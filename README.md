Empowering the Visually Impaired – Voice-Based Email Management System,

A robust voice-based email management system designed to empower visually impaired individuals to manage their emails independently using voice commands. Developed using Java, Spring Boot, Speech Recognition, Text-to-Speech, Gmail API, and MySQL. Includes features such as voice-based email reading, composing, sending, replying, deleting, and inbox management with secure authentication and hands-free accessibility.
